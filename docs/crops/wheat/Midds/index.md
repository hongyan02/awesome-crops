# 次粉

次粉，又称黑面、黄粉、下面、三等粉等，是小麦加工过程中产生的副产物。由种皮、果皮、糊粉层、胚及部分胚乳组成，富含蛋白质、膳食纤维、维生素和矿物质，淀粉含量约30%，产量约占小麦籽粒总量的4%。其蛋白质含量为12.5%-17%，主要由清蛋白、球蛋白、麦胶蛋白和麦谷蛋白构成

## 质量指标

次粉按照灰分含量一般分为：**2.5次粉**、**3.0次粉**、**4.0次粉**，分别对应国标文件[NY/T 211-2023](https://std.samr.gov.cn/hb/search/stdHBDetailed?id=F997A516CB591C94E05397BE0A0A70DA)中的**一级**、**二级**、**三级**指标。根据厂家需求不同，也会有3.5次粉、4.5次粉等各种灰分含量不同的次粉。
