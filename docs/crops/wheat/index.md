# 小麦

[小麦](https://baike.baidu.com/item/%E5%B0%8F%E9%BA%A6/10237)（学名：Triticum aestivum）是禾本科小麦属的一种一年生或越年生的草本植物，花果期5-7月，是全球最重要的三大粮食作物之一（另外两种是水稻和玉米）。

## 植物特征

- **结构**：由根、茎、叶、穗和种子（麦粒）组成。其茎秆直立，中空有节；穗状花序直立，通常带有芒（即麦穗上细长的针刺）。

- **生长环境**：小麦具有很强的适应性，但在温带地区生长最为理想。根据播种季节的不同，主要分为：
  - **[冬小麦](https://baike.baidu.com/item/冬小麦/508343?fromModule=lemma_inlink)**：秋季播种，经过冬季休眠（春化作用），次年夏季收获。
  - **[春小麦](https://baike.baidu.com/item/春小麦/508357?fromModule=lemma_inlink)**：春季播种，当年秋季收获。

## 产地

中国小麦分布地域广泛，地理气候环境多样，既能种植[冬小麦](https://baike.baidu.com/item/冬小麦/508343?fromModule=lemma_inlink)又能种植[春小麦](https://baike.baidu.com/item/春小麦/508357?fromModule=lemma_inlink)。

小麦主产区主要种植冬小麦，种植面积依次为[河南](https://baike.baidu.com/item/河南/132980?fromModule=lemma_inlink)、[山东](https://baike.baidu.com/item/山东/155740?fromModule=lemma_inlink)、[安徽](https://baike.baidu.com/item/安徽/37014?fromModule=lemma_inlink)、[江苏](https://baike.baidu.com/item/江苏/154268?fromModule=lemma_inlink)、[河北](https://baike.baidu.com/item/河北/65777?fromModule=lemma_inlink)、[四川](https://baike.baidu.com/item/四川/212569?fromModule=lemma_inlink)、[湖北](https://baike.baidu.com/item/湖北/173862?fromModule=lemma_inlink)、[陕西](https://baike.baidu.com/item/陕西/193811?fromModule=lemma_inlink)、[新疆](https://baike.baidu.com/item/新疆/132263?fromModule=lemma_inlink)、[山西](https://baike.baidu.com/item/山西/188460?fromModule=lemma_inlink)、[甘肃](https://baike.baidu.com/item/甘肃/226159?fromModule=lemma_inlink)等11个省（区），约占全国冬小麦总面积的95%左右。栽培春小麦的主要有[内蒙古](https://baike.baidu.com/item/内蒙古/173741?fromModule=lemma_inlink)、新疆、甘肃、[青海](https://baike.baidu.com/item/青海/31638?fromModule=lemma_inlink)、[黑龙江](https://baike.baidu.com/item/黑龙江/7351?fromModule=lemma_inlink)、[宁夏](https://baike.baidu.com/item/宁夏/15715?fromModule=lemma_inlink)、[天津](https://baike.baidu.com/item/天津/132308?fromModule=lemma_inlink)、河北、[西藏](https://baike.baidu.com/item/西藏/130045?fromModule=lemma_inlink)等省（区），以内蒙古面积最大，西藏单产最高，其次为新疆。

## 产量

近五年来，中国小麦生产在经历2023年面积扩张但单产受灾的波动后，成功转向以科技驱动的单产提升模式，连续两年稳产于1.4亿吨高位，生产效率达到历史顶峰。
