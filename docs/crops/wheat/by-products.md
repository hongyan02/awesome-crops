# 副产物

小麦加工过程中，除主产品面粉外，还会产生麦麸、次粉、胚芽等副产物。这些副产物虽然不是主要商品粉，但具有一定的营养价值和经济价值，常用于饲料加工、食品加工、油脂提取及其他深加工领域。

## 麦麸

麦麸是小麦制粉过程中分离出的外层皮壳部分，主要来源于小麦籽粒的麸皮层。

麦麸通常呈片状、碎片状或细碎屑状，颜色多为浅褐色、黄褐色。其特点是粗纤维含量较高，含有一定的蛋白质、矿物质和维生素。

麦麸主要用途包括：

1. **饲料原料**  
   常用于猪、牛、羊、禽类等饲料中，可提供纤维、蛋白和部分能量。

2. **食品加工**  
   部分优质麦麸可用于全麦食品、膳食纤维产品等。

3. **发酵及其他用途**  
   可作为发酵原料或辅料，用于部分农业和工业加工场景。

麦麸的质量通常关注水分、粗蛋白、粗纤维、灰分、霉变、生虫、结块、异味以及呕吐毒素、赤霉烯酮等指标。

## 次粉

次粉是小麦制粉过程中产生的低等级粉类副产物，通常由部分粉质、细麸、糊粉层及少量胚乳组成。

次粉的颜色一般比普通面粉略深，粉质较细，营养成分中含有较高的蛋白质、矿物质和一定量的纤维。由于其中夹杂部分麸皮成分，灰分通常高于普通商品面粉。

次粉主要用途包括：

1. **饲料加工**  
   是常见的饲料原料，可用于猪料、禽料、水产料等，提供能量和蛋白。

2. **工业加工**  
   可用于发酵、酶制剂、淀粉糖等相关加工领域。

3. **低端食品或辅料用途**  
   在符合食品安全和质量要求的情况下，可用于部分食品加工辅料。

次粉质量一般关注水分、粗蛋白、灰分、粗纤维、粉色、气味、霉变、生虫及毒素指标。不同厂家、不同等级的次粉质量差异较大，实际交易中需要重点看蛋白、灰分和杂质情况。

## 胚芽

小麦胚芽是小麦籽粒中具有发芽能力的部分，位于小麦籽粒的一端，是小麦中营养较集中的部位。

胚芽含有较丰富的蛋白质、脂肪、维生素E、B族维生素、矿物质等成分，营养价值较高。但由于脂肪含量相对较高，胚芽容易氧化酸败，对储存条件要求较高。

胚芽主要用途包括：

1. **食品加工**  
   可用于营养食品、谷物食品、烘焙食品、代餐产品等。

2. **油脂提取**  
   可用于提取小麦胚芽油，胚芽油中维生素E含量较高。

3. **饲料原料**  
   也可作为高营养饲料原料使用，但需要注意新鲜度和酸败问题。

胚芽质量通常关注水分、脂肪含量、气味、色泽、杂质、霉变、酸价和储存稳定性。

## 简要对比

| 类别 | 来源                 | 主要特点                         | 主要用途                 |
| ---- | -------------------- | -------------------------------- | ------------------------ |
| 麦麸 | 小麦外层皮壳         | 粗纤维高，片状或碎屑状           | 饲料、食品纤维、发酵辅料 |
| 次粉 | 制粉过程中的低等级粉 | 蛋白较高，灰分高于普通面粉       | 饲料、发酵、工业加工     |
| 胚芽 | 小麦籽粒胚部         | 营养价值高，脂肪含量较高，易酸败 | 食品、胚芽油、饲料       |

## 总结

麦麸、次粉和胚芽都是小麦加工中的重要副产物。麦麸以纤维和饲料用途为主，次粉兼具能量和蛋白价值，常用于饲料和工业加工；胚芽营养价值较高，可用于食品和油脂深加工。实际采购和使用时，应重点关注水分、蛋白、灰分、纤维、毒素、霉变、气味和储存稳定性等指标。
