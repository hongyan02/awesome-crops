# 小麦粉(面粉)

小麦粉(面粉)是由小麦经过碾磨制粉，部分或全部去除麸皮和胚，用于制作面制食品的产品。

## 营养价值

小麦粉中含有[蛋白质](https://baike.baidu.com/item/蛋白质/309120?fromModule=lemma_inlink)、[淀粉](https://baike.baidu.com/item/淀粉/781685?fromModule=lemma_inlink)、[脂肪](https://baike.baidu.com/item/脂肪/85926?fromModule=lemma_inlink)、[维生素](https://baike.baidu.com/item/维生素/161385?fromModule=lemma_inlink)和无机盐等。小麦粉中的蛋白质含量比其他谷物产品高，一般在11%以上，高的可达15%--20%，由[麦醇溶蛋白](https://baike.baidu.com/item/麦醇溶蛋白/5601194?fromModule=lemma_inlink)和[麦谷蛋白](https://baike.baidu.com/item/麦谷蛋白/5779960?fromModule=lemma_inlink)组成，它们吸水后可揉成具有粘弹性的面筋质，因此用小麦粉可制成独特品质和[风味](https://baike.baidu.com/item/风味/133106?fromModule=lemma_inlink)的[食品](https://baike.baidu.com/item/食品/174284?fromModule=lemma_inlink)。小麦粉中[碳水化物](https://baike.baidu.com/item/碳水化物/12760628?fromModule=lemma_inlink)含量在70%以上，主要由淀粉、纤维素和其他[糖类](https://baike.baidu.com/item/糖类/1513051?fromModule=lemma_inlink)组成，是人体能量的主要来源。

## 质量指标

小麦粉一般分为：**精制粉**、**标准粉**、**普通粉**三种类别。其类别划分按照现行(2023-01-01实施)国家标准文件[GB/T 1355-2021](https://openstd.samr.gov.cn/bzgk/gb/newGbInfo?hcno=7FBA509CDA87E5C9DE846BBC077430B4&refer=outter)中的各种质量指标进行划分，分别为：**加工精度**（小麦粉中残留麸皮碎片的程度）、**灰分含量**(以干基计)、**脂肪酸值**(以湿基，KOH计)、**水分含量**、**含砂量**、**磁性金属物**、**色泽**、**气味**、**外观形态**、**湿面筋含量**。
